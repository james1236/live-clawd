He needs the Claude Code plugin too. In Claude Code, run:

/plugin marketplace add james1236/live-clawd
/plugin install clawd@live-clawd

then start a new session (or /reload-plugins). This page notices when it connects.

One more thing: let Clawd keep changes under wraps.

With your OK, he snapshots what's about to change, so the new version only appears as he paints, wipes or vacuums it, instead of popping in before he gets there. It only ever captures the visible localhost tab he's working on, and nothing leaves your computer.
